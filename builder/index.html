PanelKit

View Assist · button-card · grid areas

Blocks

Pick a block, then tap the grid cells it should occupy. The navbar floats above the view and needs no cell.

Settings

Tap a block in the list to set its content and style.

Background & links

A target without a leading / counts as a view name and is appended to this path, e.g. music → /view-assist/music. Starting with /: any HA path. Starting with https://: external URL.

Grid

Sizes accept any CSS grid value: 1fr, min-content, 15vh, 200px.

Preview

Shows placement, sizing and navbar style. Real card content is rendered by Home Assistant.

    3. 
        
  3. Add a card → Manual, clear its contents, paste the YAML, save.
    4. 
        
  4. Open it with view_assist.navigate or from the navbar of another view.
