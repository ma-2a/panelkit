    Open a block to edit it. The selected block is what you place when tapping grid cells.

    View settings

    Link targets work the same everywhere. A plain name like music opens that view on this dashboard. A path like /lovelace/0 opens any dashboard. script.x or scene.x runs it. https:// opens a website.

    Grid

    Tap cells to give them to the selected block. Sizes take any CSS grid value, for example 1fr, min-content, 15vh or 90px.

    How to install
    
      
      
        
    1. Install the cards listed above from HACS under Frontend, then reload the browser.
      2. 
        
    2. In the View Assist dashboard, add a view with exactly the name above and the Panel (1 card) type.
      3. 
        
    3. Add a card, choose Manual, clear it, paste the YAML, save.
      4. 
        
    4. Open it with view_assist.navigate or from the navbar of another view.
      5. 
      
    
      
    Building a tab set? Create one view per template with the same navbar, and the active tab lights up on each.
